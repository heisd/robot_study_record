# 机器人学习记录 · HTML 笔记

使用静态 HTML 页面整理机器人开发环境搭建过程，主要记录 Ubuntu、Jetson 与 SDK Manager 相关操作，并将配图保存在仓库内，便于按顺序回顾。

## 仓库结构

| 路径 | 说明 |
| --- | --- |
| [html/main.html](./html/main.html) | 主要学习页面，包含操作文字、代码片段和图片引用 |
| [css/main.css](./css/main.css) | 样式练习文件；页面自身也包含内联样式 |
| [image/](./image) | 教程截图与操作配图 |

这是一份静态学习资料，没有 Node/Python 后端，也没有 npm 构建步骤。

## 本地查看

```bash
git clone --branch main https://github.com/heisd/robot_study_record.git
cd robot_study_record
```

之后用文件管理器进入 `html/`，使用浏览器打开 `main.html`。直接在 GitHub 中点击 HTML 文件通常看到的是源码，而不是完整页面。

如果本机安装了 Python，也可从仓库根目录启动临时静态服务器：

```bash
python -m http.server 8000 --bind 127.0.0.1
```

浏览器访问 `http://127.0.0.1:8000/html/main.html`，停止时在终端按 `Ctrl+C`。这是可选的查看方法，Python 并非页面本身的依赖。

## 页面内容

当前页面从开发环境准备开始，记录 Ubuntu 安装、Jetson 系统准备、NVIDIA 账号与 SDK Manager 操作等学习步骤。配图使用 `../image/...` 的相对路径，适合将仓库整体下载后离线阅读。

页面中的软件安装包名和版本属于当时的实践记录。实际刷机和安装应先核对主机系统、目标 Jetson 型号以及配套版本，不能把笔记中出现的“最新版”理解为当前可用版本。

## 如何继续维护

1. 新增文字时编辑 `html/main.html`，按步骤设置标题。
2. 将配图放入 `image/`，使用相对路径引用。
3. 保留 `html/` 与 `image/` 的目录关系。
4. 在浏览器中刷新页面，检查图片、链接与代码格式。
5. 补充经验时记录适用设备和软件版本，便于以后复现。

截图文件名包含空格时，HTML 引用应与实际名称完全一致；文件名大小写在部分系统中也会影响加载。

## 常见问题

| 现象 | 检查方式 |
| --- | --- |
| GitHub 上只看到源码 | 下载后用浏览器打开，或使用本地静态服务器 |
| 图片不显示 | 检查相对路径、文件名空格与大小写 |
| 样式修改没有变化 | 页面包含内联样式，应确认修改的是实际生效位置 |
| 安装命令失效 | 命令记录的是历史环境，先核对文件名与设备对应版本 |

仓库保留学习页面的原始结构，README 提供阅读和维护入口，不代表页面中的全部历史安装流程已重新验证。
